# ИП Молодецкий Р. Н. — мотосервис, Новогрудок

ТО и ремонт мотоциклов, тюнинг, мотоподбор с диагностикой, обучение вождению, эвакуация и выкуп
мототехники. Телефон +375 44 454-10-30.

**Живой сайт:** https://romjjjke.github.io/molodetsky-moto/

## Что внутри

- Герой-манифест: «Мотоцикл ломается не от пробега, а от отношения» + бегущая строка классов мотоциклов.
- Шесть направлений строками-таблицей: что делаем, что входит, какой статус.
- Пин-сцена «дефектовка»: восемь пунктов осмотра перед покупкой открываются по одному, активный
  получает лаймовую засечку и пояснение. На мобильном пин снимается и все пояснения видны сразу.
- Восемь классов мотоциклов с тем, что в каждом сыпется первым.
- Шесть шагов мотоподбора, три «позиции» вместо рекламных обещаний, FAQ на `<details>`.
- Форма заявки уходит в WhatsApp, светлая панель заявки контрастирует с чёрной мастерской.

## Стек

React + Vite + TypeScript, GSAP + ScrollTrigger (лениво, только для дефектовки), Lenis.
Шрифты самохостингом: Days One + IBM Plex Sans 400/500/600, 109 KB на 8 файлов, метрические фолбэки.
Изображений нет: весь визуальный слой — типографика, линии и зерно.
